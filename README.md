# Vivero Hoja

Sitio web de un vivero ficticio de plantas de interior en San Isidro, Buenos Aires. Pre-entrega del proyecto del curso de desarrollo web.

**Sitio publicado:** https://aylingarin.github.io/vivero-hoja/

## Propósito

Presentar el vivero, mostrar las plantas disponibles, compartir reseñas de clientes y permitir enviar una consulta por un formulario de contacto.

## Qué incluye

- HTML semántico: `header`, `nav`, `main`, `section` y `footer`.
- Lista de navegación con enlaces internos.
- Productos en cards con Flexbox.
- Reseñas con CSS Grid.
- Formulario de contacto con Formspree y mapa de Google Maps (iframe).
- Media Queries para que el contacto se adapte a pantallas chicas.
- Archivo `styles.css` con Google Fonts y fondo con degradado.

## Archivos

- `index.html`
- `styles.css`
- `README.md`

## Formulario

El formulario de contacto envía los datos a través de [Formspree](https://formspree.io), que los reenvía por correo.

## Publicación

El sitio está publicado con GitHub Pages: *Settings → Pages → Source: rama `main`, carpeta `/ (root)`*.
